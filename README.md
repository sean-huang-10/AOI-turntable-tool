# AOI 光學 / 產能 / 轉盤整合計算工具

單一 HTML 頁面的 AOI（自動光學檢測）系統設計計算工具，涵蓋從相機/鏡頭選型、瑕疵偵測需求反推、產能與曝光評估，到轉盤機構評估的完整流程。純前端、無需建置或伺服器，用瀏覽器開啟 `index.html` 即可使用。

## 檔案結構

```
index.html        頁面結構與五個分頁的 HTML
css/style.css      所有樣式
js/app.js          光學/選型/產能/摘要四個分頁的計算邏輯
js/turntable.js    轉盤評估分頁的計算與 canvas 動畫邏輯
```

`js/app.js` 與 `js/turntable.js` 是各自獨立的計算模組，彼此不共用變數，但**各自都有一份 FOV 計算邏輯**（見下方「已知限制」）。

## 使用方式

直接用瀏覽器開啟 `index.html`（例如 `python3 -m http.server` 後瀏覽 `http://localhost:8000/index.html`）。所有欄位輸入後即時運算，不需送出或重新整理。頁面右上角「列印 / 另存 PDF」可將目前畫面輸出成 PDF。

## 分頁說明

### 1. 光學 / FOV 分析
輸入相機（像元尺寸、解析度）與鏡頭條件，計算單像素解析度、光學放大倍率、視野（FOV）範圍，並判斷產品在視野中的佔比是否落在合理範圍（預設 60%～85%，可調）。

- 遠心鏡：`解析度 = 像元尺寸 / 倍率`，或由已知物體實測像素反推倍率。
- CCTV 鏡頭：`倍率 = 焦距 / (工作距離 - 焦距) + 延伸環 / 焦距`，再換算解析度。
- `FOV = 解析度 × 相機解析度（寬/高）`；`產品佔比 = 產品尺寸 / FOV × 100%`。

### 2. 瑕疵需求選型
輸入欲偵測的最小瑕疵尺寸與目標 FOV，依安全精度（3/4/5 px 佔一個瑕疵）反推所需解析度、最小水平像素數與建議鏡頭倍率。

### 3. 產能 / 曝光 / Batch 最後一站距離
依移動速度、允許的 pixel shift 與光學分頁算出的解析度，計算最大容許曝光時間、所需 FPS、產能（UPH）、產品 Pitch、最小可偵測瑕疵尺寸，以及 Batch 模式下最後一站所需的機構距離，並各自標示是否符合可用曝光時間 / 相機 FPS / 可用距離限制。

### 4. 轉盤評估
從目標產能（震動盤 pcs/min）反推轉盤所需線速度、RPM、pulse/s，並可輸入實際轉速比較理論值與實際值下的物料間距是否安全。內建相機停留時間與動態模糊試算（依鏡頭類型、感光元件解析度、像素大小、曝光時間），以及「速度 → 間距」「直徑 → 間距」兩張對照表，並用 canvas 即時動畫呈現轉盤、進料軌道與相機視野。

### 5. 整合摘要
彙整前三個分頁（光學、選型、產能）的關鍵結果，方便列印存檔。

## 已知限制

- **FOV 計算邏輯重複**：「光學 / FOV 分析」與「轉盤評估」兩個分頁各自獨立計算 FOV，欄位（相機型號、鏡頭倍率、工作距離等）也是分開輸入、互不同步。若兩邊參數設定不一致，兩個分頁算出的 FOV 可能對不起來，使用時須留意以哪一個分頁的設定為準。
- **無資料持久化**：重新整理頁面後所有輸入會回到預設值，無存檔/讀檔或匯出 CSV/JSON 功能，僅能整頁列印/另存 PDF。
- **輸入防呆有限**：部分公式（如 CCTV 模式的 `工作距離 - 焦距`）僅用極小值下限（如 `Math.max(x, 0.0001)`）避免除以零，並未對不合理的輸入（例如工作距離小於焦距）跳出提示。
